# Money Flow — Official Landing Website

> The ultra-modern, high-performance web showcase for **Money Flow** — the private wealth manager engineered for career transition ledgers, emotional spend sentiment diagnostics, and physical cash reconciliations.

---

## 🌟 Key Features

- **🌓 Dynamic Dual-Theme Architecture**: Seamless auto-detection of user OS color scheme (Dark & Light) with persistent storage and smooth CSS transitions.
- **📱 Interactive Mobile Live Preview**: Interactive smartphone simulator demonstrating real-time Analytics, Multi-Company Career Ledgers, and Spend Quality Sentiment scoring.
- **💼 Multi-Company Career Ledgers**: Automated carry-forward calculation engine connecting accumulated savings and investments across job transitions.
- **🎯 Emotional Spend Sentiment Scoring**: Real-time Spend Quality Ratio distinguishing productive capital growth from impulse drains.
- **🛡️ Privacy Charter & Cold-Start Resilience**: Complete non-custodial data protection charter, isolated multi-tenant architecture, and server wake-up shield.
- **📋 In-Depth Legal Transparency**: Structured, readable Privacy Policy and Terms of Service with interactive scroll-spy navigation.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v18.17.0 or newer
- **npm** or **yarn** / **pnpm**

### Installation

```bash
# Clone repository
git clone git@github.com:KS-Money-Flow/landing-site.git

# Navigate to project root
cd landing-site

# Install dependencies
npm install

# Launch development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

### Production Build

```bash
# Compile optimized static output
npm run build

# Start production server
npm run start
```
